# Slop-Detector
## Firefox Extension that gives a proper warning for projects labeled as AI

### Main Feature:
Gives a Warning overlay every time you access a page that has modrinth's AI Label

### Why use this?
Sometimes you might miss the ___"ai-generated"___ label at the bottom of the sidebar and go directly to the download page, this extension aims to prevent that by giving you a __clear warning__ before you engage with the page at all, so you don't have to go searching for an AI label every time you open a project.

### How does it work?
It scans the page for the sparkle icon right next to the warning and the the "ai generated" text right beside it, so that the extension won't flag a project as ai unless it has modrinth's AI label.

### Downsides:
Since this is relying entirely on modrinth's AI label, sadly the extension can't detect _obviously ai generated_ projects UNLESS they are tagged as ai generated by modrinth themselves.
